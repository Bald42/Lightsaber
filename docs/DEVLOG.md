## 2026-11-22
Сделали: разобрались, почему телефон не коннектится к хосту. Нашли и починили три слоя проблемы:
1. GetLocalIPAddress() в NetworkCodeUtility.cs подхватывала IP виртуального VPN/прокси-туннеля (Happ Tunnel) вместо реального Wi-Fi адаптера — PIN хоста считался от левого адреса. Переписали: берём только Ethernet/Wi-Fi адаптер с настоящим шлюзом (не 0.0.0.0), виртуальные туннели у шлюза просто не имеют.
2. Windows Firewall не пускал входящий UDP 7777 для текущей версии Unity Editor — добавили приложению разрешение (Private+Public) и отдельное правило на порт.
3. Роутер Bald5g (MTS) изолирует Wi-Fi клиентов друг от друга — подключение по PIN и файрвол в полном порядке, но пакеты между телефоном и ПК режутся самим роутером. Подтвердили тестом: подключение через раздачу с телефона вместо роутера сработало сразу.
Остановились: подключение по PIN рабочее (проверено через точку доступа с телефона), через основной роутер Bald5g — нет.
Дальше: найти в панели МТС настройку изоляции клиентов (в Wi-Fi → Дополнительно для 2.4/5GHz её нет, Межсетевой экран не проверяли) либо постоянно использовать раздачу с телефона. После этого — гироскоп с нуля (см. DECISIONS.md).
