# Lightsaber

Проект игры с управлением мечом через гироскоп смартфона в локальной сети (Wi-Fi).

## ? Технический стек
* **Unity Version:6000.0.71f1** 
* **Target Platforms:** PC (Display / Server), Android (Controller / Client)
* **Networking:** Mirror 

## ? Архитектура связи
1. **PC (Host / Server):** Принимает данные поворота (Quaternion) и отображает модель меча.
2. **Android (Client):** Считывает `Input.gyro.attitude`, калибрует нуль и шлет пакетом на ПК по UDP.
